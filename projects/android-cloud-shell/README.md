# Hacking Android through the Cloud: AWS Reverse Shell

## 🛠️ Tech Stack
**Technologies:** `AWS EC2, Kali Linux, Metasploit, msfvenom`

## 📖 Project Overview
Deployed Kali Linux on an AWS EC2 instance to serve as a cloud-based Command & Control (C2) server for capturing Meterpreter reverse shells.

## 🚀 Key Learnings
* Configuration and deployment of `AWS EC2, Kali Linux, Metasploit, msfvenom` in a production-like environment.
* Deep-dive analysis of system logs and network traffic.
* Documentation of technical workflows for architectural clarity.
