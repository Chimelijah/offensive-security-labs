# Metasploit Payload Injection in Android APKs

## 🛠️ Tech Stack
**Technologies:** `APKTool, Smali, zipalign, apksigner`

## 📖 Project Overview
Decompiled an open-source Android game, injected a malicious Smali payload, modified permissions, and re-signed the APK.

## 🚀 Key Learnings
* Configuration and deployment of `APKTool, Smali, zipalign, apksigner` in a production-like environment.
* Deep-dive analysis of system logs and network traffic.
* Documentation of technical workflows for architectural clarity.
